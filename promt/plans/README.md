## Соглашения

- Статусы: `[ ]` — не начато, `[~]` — в работе, `[x]` — готово, `[—]` — отменено/не делаем.
- Приоритеты: **P0** — блокирует работу пользователей или противоречит ТЗ; **P1** — заметный дефект/незавершённая задача; **P2** — техдолг; **P3** — улучшения.
- Ссылки на код даны в формате `путь:строка` **на момент 2026-11-06**. После правок номера строк сдвигаются — ищите по приведённым в плане анкорам (фрагментам кода).
- Инварианты проекта (не нарушать): уникальность `ProductionRecord (pcs_no, subop_no, created_date)`; импорт через `ignore_conflicts=True`; обязательные колонки Excel; `Cache-Control: no-store` для HTML отчётов №2, №3 и экспорта №3.
- Новые зависимости не добавляются.
