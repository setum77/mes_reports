## 1. Цели

1. **Завершить начатую переработку отчёта №5** «Повторные проходы станций» — она уже реализована в рабочем дереве, но не закоммичена, не покрыта тестами и содержит прямое нарушение ТЗ (жёсткое ограничение 50 строк).
2. **Устранить найденные дефекты** (пункт B): падение поиска в админке, HTTP 500 на некорректных датах, рассинхронизация документации и кода, опечатки, неверные умолчания экспорта.
3. **Снять техдолг, который мешает дальнейшим доработкам**: N+1 в отчёте №1, O(n²) в сортировке, фильтрация по лоту в Python вместо SQL, мёртвая модель `Report5Comment`.
4. **Привести деплой в порядок**: `.dockerignore`, дефолтный пароль администратора, дефолтный `SECRET_KEY`.

Не входит в план: новые отчёты, изменение бизнес-логики расчётов (FOL/BOL, % NG, Diff), смена стека, введение линтера/форматтера.

## 2. Принципы выполнения

- **Минимальные изменения**: одна задача — один логически цельный дифф, не трогаем соседний код «заодно».
- **Сначала тест, потом правка** там, где поведение воспроизводимо (B1–B6, B9).
- **Не ломать инварианты**: уникальность `ProductionRecord`, `ignore_conflicts=True`, обязательные колонки Excel, `no-store` для отчётов №2/№3 и экспорта №3.
- **Проверка после каждой задачи**: `manage.py check` + узкий набор тестов + полный `pytest` перед коммитом.
- **Без новых зависимостей** (правило AGENTS.md).
- Перед правкой файла — прочитать его; после — сообщить изменённые файлы и фактически выполненные команды.

## 6. Ограничения среды и риски

| Риск | Влияние | Меры |
|---|---|---|
| Служба PostgreSQL на машине разработки остановлена | БД-тесты не запускаются (`OperationalError`) | Запустить `postgresql-x64-17` или тестовый контейнер перед этапом 1 |
| `uv` недоступен в песочнице (нет доступа к `AppData\Local\uv\cache`) | `uv run pytest` падает | Использовать `.venv\Scripts\python.exe -m pytest`; в командной строке планов указывать оба варианта |
| Правки в `production/admin.py` и `production/models.py` требуют миграций | Риск для существующей БД | B1 — без миграций (только `search_fields`); H4 — только при явном решении удалять модель |
| Изменение `REQUIRED_COLUMNS`/дедупликации | Может сломать импорт исторических выгрузок | B7 — только документация, код парсера не трогаем |
| Тесты в `tests/test_reports.py` используют `Report5Comment` | Удаление модели сломает тесты админки/дашборда | H4 выполнять отдельным коммитом с правкой тестов, моделей, админки, бэкапа и дашборда |

