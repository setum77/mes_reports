1. В базу данных внести дополнения. К блокам имеющим SN добавить свойства: 
	1. Defect - брак, логическое поле. У блоков уже есть поле прохождения станций (Ok, NG), поле Defect другое, его устанавливает администратор, указывает окончательную отправку в Брак. По умолчанию всем существующим SN установить 0.
	2. Photos - возможность загрузить и прикрепить фотографии к SN. Фотографий может быть несколько. 
2. Переделываем четвертый отчет "Отчет по браку"
	1. В поле Фильтр помимо основного существующего фильтра добавить еще один фильтр, справа от основного:  "Брак" - показывает основную таблицу по Defect = 1, "Не закончили производство" -  показывает основную таблицу по условию: SN в производстве 010 - ok и нет статуса 130 - ok. По умолчанию показывать "Последние 90 дней" и "Брак"
	2. В основной таблице добавляем поле Photos со списком загруженных фотографий. Имена фотографий являются ссылкой для просмотра фотографий. Подключить простой вьювер фотографий.  Фотографии можно открыть и просмотреть, если их несколько предусмотреть стрелки для перелистывания, а также увеличить, уменьшить. В дальнейшем вьювер будет использоваться и в других отчетах.
	3. Добавить кнопку "Описание отчета", логика и положение как в отчете №8 "по станциям". Составить описание отчета
3. Переделываем шестой отчет "Отчет по SN"
	1. В сводку добавляем редактируемое поле Defect, устанавливать может только администратор, перед сменой статуса спросить подтверждение.
	2. В сводке добавляем поле Фотографии, с кнопкой "+" для загрузки новых фотографий
	3. В поле Фотографии список загруженных фотографий, справа от имени кнопки-значки - Переименовать, Удалить. Перед удалением спросить подтверждение.
	4. Описание отчета откорректировать с учетом изменений.
