## Что изменено

### src/reports/queries.py
- Добавлен импорт `from collections import Counter`.
- Добавлена функция `report6_summary(pcs_no)` — возвращает сводную информацию:
  - `pcs_no`, `lot_number`, `production_spec`
  - `assembly_start` — дата/время первой записи на станции 010 (начало сборки)
  - `assembly_end` — дата/время последнего прохода станции 130 с OK (окончание сборки)
  - `completed` — `True`, если сборка завершена (станция 130 OK найдена)
  - `last_station`, `last_station_date` — последняя станция и её дата/время (для незавершённой сборки, теперь используется последняя запись в хронологическом порядке, а не только с OK)
  - `last_station_status` — статус последней станции (OK или NG)
  - `double_passes` — станции, пройденные более 2 раз (формат: "20 - 3, 70 - 2")
  - `comment` — комментарий из модели `SNComment`
- Использует `REPORT4_STATION_NAMES` для перевода номера станции в название, с fallback на `translate_workstation_name`.

### src/reports/views.py
- Добавлен импорт `report6_summary` из `reports.queries`.
- Добавлена константа `REPORT6_DESCRIPTION` — текст описания отчёта (аналогично `REPORT8_DESCRIPTION`), включает описание всех новых полей.
- `Report6View`:
  - Вызывает `report6_summary(pcs_no)` и передаёт `summary` в контекст.
  - Отслеживает последние просмотренные SN в сессии (`report6_recent_sns`, максимум 50 штук).
  - Передаёт `recent_sns`, `recent_sns_comments` (dict для подстановки комментариев в sidebar) и `report6_description_lines` в контекст.
  - Устанавливает `Cache-Control: no-store` для HTML-ответа.
- `SNCommentEditView.post`:
  - После сохранения комментария перенаправляет на `reports:report6?pcs_no=<pcs_no>` вместо `reports:report4`.
- `Report6ExportView`:
  - Добавлен лист "Сводка" с полями: SN, Лот, Спецификация, Начало сборки, Окончание сборки, Статус, Последняя станция, Статус последней станции, Комментарий, Двойные проходы.
  - Убраны столбцы «Lot no.», «Production spec.», «Комментарий» из листа «Отчет по SN» (соответствуют удалённым колонкам в HTML-таблице).

### src/templates/base.html
- Добавлен Bootstrap Icons CDN: `<link href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.css" rel="stylesheet">`.

### src/templates/reports/report6.html
- **Левая колонка** (sidebar): карточка «Последние просмотренные SN» со списком ссылок (до 50 штук), рядом с каждым SN показываются first 15 символов комментария (через `truncatechars:15` и `get_item` фильтр).
- **Сводка** (summary card):
  - SN, лот, спецификация, начало сборки.
  - Окончание сборки: зелёный badge при `completed`, красный badge с названием последней станции, статусом (OK/NG) и датой/временем при незавершённой сборке (без надписи "Последняя станция:").
  - Комментарий с кнопкой-значком ручки (`<i class="bi bi-pencil">`, `title="Редактировать комментарий"`) — только для staff.
  - Двойные проходы: станции с >2 проходами.
- **Основная таблица**: убраны колонки «Lot no. - Лот», «Production spec. - Спецификация», «Комментарий».
- **Модальное окно** «Описание отчёта» — аналогично отчёту №8.

### src/templates/reports/sn_comment_form.html
- Кнопка "Отмена" перенаправляет на `reports:report6?pcs_no={{ pcs_no }}` вместо `reports:report4`.
