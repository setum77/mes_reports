### Этап 3. Переделка Отчёта №4 «Отчет по браку»

#### 3.1 Фильтр «Брак / Не закончили производство»
- Существующий фильтр `filter` отвечает за период (30d, 90d, 180d, month, year, period, lot).
- Добавляется параметр `defect_filter` со значениями:
  - `defect` — SN с `defect=True` + `ManualDefect`.
  - `in_progress` — SN прошли 010 с OK, но не прошли 130 с OK.
- По умолчанию: `filter=90d`, `defect_filter=defect`.

#### 3.2 Столбец Photos
- В `report4_defects()` добавить в каждую строку `photos` — список `SNPhoto`.
- В шаблоне: имена файлов как ссылки на `/media/...`, кнопка просмотра → photo_viewer.

#### 3.3 Кнопка «Описание отчёта»
- Константа `REPORT4_DESCRIPTION` в `views.py`.
- Кнопка рядом с «Экспортом в Excel» (левее), как в report8.html.

### Этап 4. Переделка Отчёта №6 «Отчет по SN»

#### 4.1 Поле Defect в сводке
- `report6_summary()` возвращает `defect` (boolean).
- В шаблоне: переключатель чекбокс, только для `user.is_staff`.
- `SNSetDefectView` (POST, admin only) с подтверждением через `confirm()`.

#### 4.2 Поле Фотографии в сводке
- `SNPhotoUploadView` (POST, admin only) — загрузка через форму/modal.
- Список фото с кнопками «Переименовать» (pencil) и «Удалить» (trash).
- `SNPhotoRenameView`, `SNPhotoDeleteView` (POST, admin only, confirm).

#### 4.3 Обновление описания
- `REPORT6_DESCRIPTION` пополняется описанием полей Defect и Фотографии.
