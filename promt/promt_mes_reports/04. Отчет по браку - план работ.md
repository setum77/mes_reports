## Этап 1. База данных

### 1.1 Поле `Defect` в `ProductionRecord`

**Файлы:**
- `src/production/models.py` — добавить поле в модель.
- `src/production/admin.py` — добавить поле в `readonly_fields` (ProductionRecord — read-only для staff).
- `src/production/migrations/0003_defect_field.py` — новая миграция.

**Действия:**
- Добавить в `ProductionRecord`:
  ```python
  defect = models.BooleanField("Defect — брак", default=False)
  ```
- Миграция: `AddField` с `default=False`.
- Для существующих записей: `RunPython` или `default=False` в миграции установит всех в `0` (False).
- В `ProductionRecordAdmin`: добавить `defect` в `readonly_fields` (т.к. ProductionRecord read-only).

**Ограничения (из AGENTS.md):**
- Сохранить `unique_together = ("pcs_no", "subop_no", "created_date")`.
- ProductionRecord остаётся read-only в админке (add/change/delete disabled).

### 1.2 Модель `SNPhoto`

**Файлы:**
- `src/production/models.py` — новая модель.
- `src/production/admin.py` — регистрация модели в админке.
- `src/production/migrations/0003_snphoto.py` — новая миграция.

**Модель:**
```python
class SNPhoto(models.Model):
    pcs_no      = models.CharField("Серийный номер БУ", max_length=100, db_index=True)
    image       = models.ImageField("Фотография", upload_to="sn_photos/%Y/%m/%d/")
    caption     = models.CharField("Подпись / имя", max_length=255, blank=True, default="")
    uploaded_by = models.CharField("Кто загрузил", max_length=100, blank=True)
    uploaded_at = models.DateTimeField("Загружено", auto_now_add=True)
```

**Регистрация в админке:** `SNPhotoAdmin(StaffBusinessModelAdmin)` с `list_display`, `search_fields`, `list_filter`.

**Ограничения:**
- `MEDIA_URL = "/media/"` и `MEDIA_ROOT` уже настроены в `base.py`.
- Docker: `media_volume:/app/src/media` и nginx `location /media/` уже настроены.
- Потребуется Pillow (`pip install Pillow`) для `ImageField`. **Требует согласования перед изменением зависимостей.**

## Этап 3. Переделка Отчёта №4 «Отчет по браку»

### 3.1 Новый фильтр «Брак / Не закончили производство»

**Файлы:**
- `src/reports/views.py` — `Report4View`.
- `src/reports/queries.py` — функция `report4_defects()`.
- `src/templates/reports/report4.html` — шаблон фильтра.
- `src/reports/urls.py` — при необходимости новые эндпоинты.

**Логика:**
- Существующий фильтр `filter` отвечает за период/lot.
- Добавить новый параметр `defect_filter` (select справа):
  - `"defect"` — показывать Брак: `defect=True` на ProductionRecord + `ManualDefect`.
  - `"in_progress"` — Не закончили производство: SN прошли 010 с OK, но не прошли 130 с OK.
- **По умолчанию:** `filter=90d`, `defect_filter=defect`.

**Изменения в `queries.py`:**
- `report4_defects(start_date, end_date, defect_filter='defect', limit=None)`
  - `defect`: добавить к SQL-запросу условие `defect=True` (или объединить с ManualDefect).
  - `in_progress`: текущая логика `report4_defects` уже реализует "не прошли 130 с OK" — использовать как есть.

### 3.2 Столбец Photos в таблице

**Файлы:**
- `src/reports/queries.py` — добавить в каждую строку `photos` (список объектов SNPhoto).
- `src/templates/reports/report4.html` — колонка Photos со ссылками и кнопкой просмотра.

**Логика:**
- В `report4_defects()` для каждого `pcs_no` загружать `SNPhoto.objects.filter(pcs_no=pcs_no).order_by(...)`.
- Отображать список имён файлов как ссылки на `/media/...`.
- Кнопка/ссылка «Просмотр» → открывает photo_viewer.

### 3.3 Кнопка «Описание отчёта»

**Файлы:**
- `src/reports/views.py` — константа `REPORT4_DESCRIPTION`, передача в контекст.
- `src/templates/reports/report4.html` — кнопка + модальное окно (как в report8.html).

**Описание отчёта №4:**
> Отчёт «Брак» показывает блоки БУ с отметкой «Defect» (брак), выставленной администратором, а также вручную добавленные браки и серийные номера, не завершившие производку (прошли станцию 010 с OK, но не дошли до 130 с OK).
> Фильтры: период (Последние 30/90/180 дней, Месяц, Год, Произвольный период, По лоту) и тип выборки (Брак / Не закончили производство). По умолчанию: Последние 90 дней + Брак.

## Риски и зависимости

- **Pillow** требуется для `ImageField`. Требует согласования перед `uv pip install Pillow`.
- **Defect на уровне ProductionRecord** — одна запись = одно прохождение станции. `defect` устанавливается на все записи SN. Можно рассмотреть вынос в отдельную модель `SNDefect` (pcs_no + defect + установивший + дата), но по требованию поле добавляется к записям с SN.
- **ManualDefect** уже существует — в экспорте и фильтре «Брак» учитывать и его.
- **Cache-Control: no-store** для report4 (рекомендуется, т.к. динамический).
